# JSWorkManager

Windows용 업무 Queue 관리 애플리케이션입니다.

## 주요 기능

- 업무 등록, 수정, 완료 및 삭제
- 중요도와 마감일 관리
- 마감 7일 전부터 하루 단위 색상 강조
- 기간을 설정할 수 있는 업무 요약 및 복사
- 크기 조절 가능한 플로팅 Queue 위젯
- 일반 모드와 다크 모드
- 시스템 트레이 실행 및 설정

## 개발 환경

- C++17
- Qt 5.9.9
- Visual Studio 2022
- SQLite

`JSWorkManager.sln`을 Visual Studio에서 열어 x64 구성으로 빌드할 수 있습니다.
